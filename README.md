## 🦚 About The Project

**Vrindavan Poshakh** is a modern e-commerce platform dedicated to Krishna Poshakh and devotional Shringar products.

The platform is designed to provide devotees with a simple and premium shopping experience for:

* 👑 Krishna Poshakh
* 👑 Mukut / Crown
* 💎 Krishna Jewellery
* 📿 Mala / Haar
* 🧥 Sweaters & Winter Poshakh
* 👘 Dhoti / Vastra
* 🪈 Bansuri
* 🦚 Peacock Feathers
* 🌸 Shringar Accessories
* ✨ Complete Shringar Sets
* 🎉 Festival Collections

The application follows a **mobile-first, desktop-responsive** design approach and is planned to evolve from a frontend prototype into a complete production-ready e-commerce platform.

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/vrindavan-poshakh.git
```

## 2. Enter the Project

```bash
cd vrindavan-poshakh
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

# 🔑 Environment Variables

Create a `.env` file:

```env
VITE_API_URL=
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```

When backend integrations are implemented, additional environment variables will be added for:

* Razorpay
* Shiprocket
* Firebase
* FastAPI
* Other third-party services

**Never commit `.env` files or secret keys to GitHub.**
